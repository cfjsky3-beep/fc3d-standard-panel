# 福彩3D标准盘原型

基于既有时时彩、快三标准盘原型的页面结构和交互制作。彩种内容替换为福彩3D，包含客户端、代理后台、总后台和玩法规则总表。

## 内容范围

- 31个福彩3D标准盘玩法，分为三星、前二、后二、定位胆、不定胆、龙虎六组
- 玩法名称、奖金结构、限红参数和赔率取自开云彩票福彩3D当前标准盘配置
- 玩法说明采用老竞品的说明格式，按福彩3D三位开奖号码改写
- 标准赔率按基础奖金乘以当前返奖率 `0.98` 计算，并向下保留四位小数

## 本地运行

```bash
npm install
npm run dev
```

## 验证与构建

```bash
npm test
npm run build:vercel
```

Vercel 构建产物输出到 `vercel-dist/`。
