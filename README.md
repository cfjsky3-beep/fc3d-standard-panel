# 福彩3D标准盘原型

基于已确认的时时彩、快三标准盘移动端框架制作，保留客户端、中控后台、商户后台、初始化数据和玩法规则。

## 内容范围

- 31个福彩3D标准盘玩法，按5个类型、10个方案、31个具体玩法组成三级目录
- 玩法证据来自开云彩票当前标准盘；玩法说明采用老竞品格式并按福彩3D规则改写
- 标准赔率按等概率开奖结果计算，含本金、无抽水；界面直接截断两位，研发数据保留六位与精确分数
- 竞品0.98商业赔率单独保存为对照证据，不作为标准赔率
- 快捷玩法取已启用玩法的推荐排序前6项，全部玩法保留完整三级菜单
- 中控与商户双重开关、玩法启停与排序、赔率、限额、订单盘口字段及后台截图
- JSON、玩法CSV、逐项赔率CSV、理论标准赔率CSV导出，生产默认关闭

三星通选的460/20奖级分配整体理论返奖率为100%，但奖级分配属于产品规则，仍标记为待业务确认，确认前不能作为正式结算口径。

## 本地运行与验证

```bash
npm install
npm test
npm run lint
npm run build:vercel
npm run export:html
```

Vercel构建产物输出到`vercel-dist/`，单文件研发原型输出为`福彩3D标准盘原型.html`。
